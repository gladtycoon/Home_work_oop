*Home_work_oop* - это проект на Python в рамках разработки ядра для интернет-магазина.

В модуле **created_classes** созданы, описаны и инициированы классы *Product* и *Category*, а в **utils** - реализовано дополнительное задание: чтение данных из JSON-файла и создание объектов вышеуказанных классов.

Покрытие кода тестами согласно *Test Coverage* составляет 100%
