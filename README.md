*Home_work_oop* - это проект на Python в рамках разработки ядра для интернет-магазина.

В модуле **created_classes** созданы, описаны и инициированы классы *Product* и *Category*,
а в **utils** - реализовано дополнительное задание: чтение данных из JSON-файла и создание объектов вышеуказанных классов.
В модуле **products_iterator** создан вспомогательный класс, с помощью которого можно перебирать товары одной категории.

Созданы приватные атрибуты цены и списка товаров, геттеры и сеттеры для чтения и изменения приватных атрибутов.

Реализовано тестирование существующих методов классов *Product* и *Category*

Покрытие кода тестами согласно *Test Coverage* составляет 95%
